\# 🚀 SkillOraAI



\*\*An AI-powered student learning and skill development platform\*\*



SkillOraAI is a Python-based learning platform designed to help students practice technical skills, improve problem-solving abilities, and track their learning progress.



\## ✨ Features



\- 🧠 DSA and aptitude practice

\- 💻 Interactive coding practice

\- 📊 Student progress tracking

\- 🔐 Student authentication

\- 🤖 AI learning assistant

\- 📚 Career and learning resources



\## 🛠️ Tech Stack



\- Python

\- Streamlit

\- SQLite

\- Machine Learning / AI components, where configured



\## ⚙️ Installation and Setup



\### 1. Clone the repository



```bash

git clone https://github.com/roshanjadhao-stack/SkillOraAI.git

cd SkillOraAI

```



\### 2. Create a virtual environment



```bash

python -m venv .venv

```



\### 3. Activate the environment



\*\*Windows PowerShell:\*\*



```powershell

.\\.venv\\Scripts\\Activate.ps1

```



\### 4. Install dependencies



```bash

python -m pip install -r requirements.txt

```



\### 5. Run the application



```bash

python -m streamlit run app.py

```



The application should open in your browser.



\## 🔒 Security



Never publish API keys, passwords, private student information, database files containing personal data, or other secrets.
